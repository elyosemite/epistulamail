La interfaz de la app, del sitio y de esta documentación viene del design system del proyecto, en [`design-system/`](https://github.com/elyosemite/epistulamail/tree/main/design-system): tokens, tipografía, colores y una página por componente. Las pantallas que muestra esta documentación usan el mismo HTML.

Una pieza nueva va primero a un borrador, con estilos solo de tokens; una vez aprobada, entra en las páginas del design system y en la app.
