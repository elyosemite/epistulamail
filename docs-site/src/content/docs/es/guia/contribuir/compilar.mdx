Requisitos: Node.js 24, pnpm 10 y Rust 1.88 o más nuevo. SQLCipher compila su propio OpenSSL, así que la compilación necesita Perl, un compilador de C y `make` en las dos plataformas.

<Tabs>
<TabItem label="Windows">

El Perl portátil de Windows lo descarga el script una vez. Queda en `.tools/` y el script define `OPENSSL_SRC_PERL` para la sesión y para el entorno del usuario.

```powershell
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
./scripts/setup-build-tools.ps1
pnpm tauri dev
pnpm tauri build
```

</TabItem>
<TabItem label="Linux">

En Debian y Ubuntu, instala las bibliotecas de Tauri, el libdbus del Secret Service y Perl:

```bash
sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev \
  libdbus-1-dev libxdo-dev build-essential pkg-config perl
```

Después:

```bash
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
pnpm tauri dev
pnpm tauri build
```

</TabItem>
</Tabs>

`pnpm tauri dev` lo ejecuta en desarrollo; `pnpm tauri build` genera el instalador en Windows y el AppImage y el `.deb` en Linux. La compilación de desarrollo usa su propia carpeta de datos y sus propios elementos en el cofre, así que no toca el EpistulaMail instalado. Para conectar cuentas en desarrollo, crea tus propios clientes OAuth y ponlos en `.env` (consulta el README).
