- **Windows 10 u 11, 64 bits**, o **Linux, 64 bits**. macOS todavía no tiene instalador.
- **WebView2 en Windows.** Ya viene con Windows 11; en Windows 10, el instalador lo descarga si falta.
- **Secret Service en Linux** (GNOME Keyring o KWallet), que guarda la clave de la base de datos y los tokens de las cuentas.
- **Espacio en disco** para los mensajes que elijas guardar sin conexión.

Para compilar desde el código, consulta [Compilar](/es/guia/contribuir/compilar/).
