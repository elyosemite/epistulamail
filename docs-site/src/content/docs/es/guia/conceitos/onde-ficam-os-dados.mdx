| Qué | Dónde |
|---|---|
| El programa | Windows: `%LOCALAPPDATA%\EpistulaMail`; Linux: el AppImage o el paquete `.deb` |
| Base de mensajes y configuración | Windows: `%APPDATA%\br.com.epistula.desktop`; Linux: `~/.local/share/br.com.epistula.desktop` |
| Clave de la base y acceso a las cuentas | Cofre del sistema: Administrador de credenciales en Windows, Secret Service en Linux (GNOME Keyring o KWallet), elementos `epistula` |

La base de datos está cifrada: un archivo copiado, una laptop perdida o un disco desechado no revelan nada sin la clave. La clave queda en el cofre del sistema, protegida por tu sesión; con la contraseña de EpistulaMail activada, también depende de ella.
