En la primera pantalla, o con el **+** de la columna de cuentas, elige **Abrir arquivo de e-mail** (abrir archivo de correo), o suelta el archivo en la ventana.

| Origen | Formato |
|---|---|
| Google Takeout | `.mbox` (las etiquetas siguen siendo etiquetas) |
| Outlook | `.pst` y `.msg` |
| Thunderbird | las carpetas del perfil |
| Apple Mail | `.mbox` exportado y `.emlx` |
| Cualquiera | `.eml` y Maildir |

El archivo se lee en tu computadora y se copia a la base cifrada; el original solo se lee. Antes de importar ves las carpetas y cuánto ocupará; después, cuántos entraron, cuántos estaban repetidos y cuántos fallaron.
