Una conversación aparece como una fila en la lista. Al abrirla, cada respuesta es una tarjeta; las no leídas quedan abiertas y el texto citado queda detrás de un "…".

El HTML de los mensajes se limpia antes de mostrarse, sin scripts. Las imágenes externas quedan bloqueadas hasta que las permitas en ese mensaje, porque le avisarían al remitente que abriste el correo.
