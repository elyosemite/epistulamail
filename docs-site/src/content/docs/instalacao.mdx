O EpistulaMail é distribuído como instalador para Windows e como AppImage e `.deb` para Linux, publicado a cada versão no [GitHub](https://github.com/elyosemite/epistulamail/releases/latest) e no botão de download do [site](https://www.epistulamail.com).

## Requisitos

- Windows 10 ou 11, 64 bits, ou Linux, 64 bits. O macOS ainda não tem instalador.
- No Windows, o WebView2, que já vem no Windows 11. No Windows 10, o instalador baixa se faltar.
- No Linux, o Secret Service (GNOME Keyring ou KWallet), que guarda a chave do banco e os tokens das contas.
- Uns 100 MB livres para o app, mais o espaço das mensagens que você guardar.

Para compilar a partir do código, veja [Compilar](/guia/contribuir/compilar/).

## Instalar no Windows

<Steps>

1. Baixe `EpistulaMail_<versão>_x64-setup.exe` no [site](https://www.epistulamail.com) ou na [última release](https://github.com/elyosemite/epistulamail/releases/latest).

2. Confira o SHA-256 do arquivo com o publicado nas notas da versão:

   ```powershell
   (Get-FileHash .\EpistulaMail_1.1.0_x64-setup.exe).Hash
   ```

3. Abra o instalador. No aviso do SmartScreen, clique em **Mais informações** e em **Executar assim mesmo**.

4. O EpistulaMail é instalado em `%LOCALAPPDATA%\EpistulaMail`, só para o seu usuário, com atalho no menu Iniciar.

</Steps>

<Aside type="note" title="Por que o aviso do SmartScreen?">
O instalador ainda não tem certificado de assinatura de código. O SmartScreen avisa sobre programas sem assinatura e sem histórico de downloads. Conferir o SHA-256 garante que o arquivo é o mesmo que foi publicado.
</Aside>

## Instalar no Linux

<Steps>

1. Baixe `EpistulaMail_<versão>_amd64.AppImage` ou `EpistulaMail_<versão>_amd64.deb` no [site](https://www.epistulamail.com) ou na [última release](https://github.com/elyosemite/epistulamail/releases/latest).

2. Confira o SHA-256 do arquivo com o publicado nas notas da versão:

   ```bash
   sha256sum EpistulaMail_1.1.0_amd64.AppImage
   ```

3. Para o AppImage, dê permissão de execução e abra:

   ```bash
   chmod +x EpistulaMail_1.1.0_amd64.AppImage
   ./EpistulaMail_1.1.0_amd64.AppImage
   ```

   Para o `.deb`, instale com o gerenciador de pacotes:

   ```bash
   sudo apt install ./EpistulaMail_1.1.0_amd64.deb
   ```

4. O app precisa do Secret Service (GNOME Keyring ou KWallet) para abrir. Se ele não estiver disponível, o EpistulaMail mostra um aviso e não altera os seus dados.

</Steps>

<Aside type="note" title="Por que o Secret Service?">
No Linux, o cofre do sistema é o Secret Service. É nele que ficam a chave do banco e os refresh tokens das contas, protegidos pela sua sessão. O EpistulaMail não guarda esses segredos em arquivo nem no banco.
</Aside>

## Versões novas

A partir da 1.0.2, o EpistulaMail verifica se há versão nova ao abrir e a cada 6 horas.

1. Quando há, aparece **uma vez** no sino: "Nova versão do EpistulaMail".
2. O clique abre a confirmação com o que mudou.
3. Em **Atualizar e reiniciar**, o app baixa a versão nova, confere a assinatura dela, fecha, instala e abre de novo.

<AppPreview name="update" />

As contas, as mensagens e as configurações continuam. Um arquivo sem a assinatura certa é recusado, então só versões publicadas pelo projeto são instaladas.

No Linux, o AppImage se atualiza do mesmo jeito. O `.deb` é atualizado pelo gerenciador de pacotes da sua distribuição, não pelo sino do app.

Quem está na 1.0.0 ou na 1.0.1 precisa instalar a 1.0.2 à mão uma vez.

## Desinstalar

No Windows, desinstale em **Configurações → Aplicativos → EpistulaMail**.

No Linux, apague o AppImage ou remova o pacote `.deb` pelo gerenciador de pacotes da sua distribuição (por exemplo, `sudo apt remove epistulamail`).

O desinstalador remove o programa. Para apagar também os dados:

1. Apague a pasta de dados: no Windows, `%APPDATA%\br.com.epistula.desktop`; no Linux, `~/.local/share/br.com.epistula.desktop`.
2. Remova os itens do serviço `epistula` do cofre do sistema: no Windows, em **Gerenciador de Credenciais → Credenciais do Windows**; no Linux, no GNOME Keyring ou no KWallet.
3. Se quiser, remova o acesso do EpistulaMail em [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

As mensagens continuam no servidor do seu e-mail.
