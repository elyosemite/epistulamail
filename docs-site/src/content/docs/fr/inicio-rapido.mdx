Installez EpistulaMail, connectez votre compte et lisez votre premier e-mail en cinq minutes environ. À la fin, votre boîte de réception sera synchronisée et stockée sur votre ordinateur dans une base de données chiffrée.

## Ce qu'il vous faut

- **Windows 10 ou 11, ou Linux**, 64 bits.
- **Un compte Gmail, Microsoft ou manuel (Autre).** Yahoo, iCloud, Zoho, GMX et AOL arrivent bientôt ; en attendant, vous pouvez [ouvrir des archives d'e-mails](/fr/guia/arquivos/abrir-um-arquivo/) sans compte.
- **Sous Linux, le Secret Service** : GNOME Keyring ou KWallet. C'est le coffre du système où se trouvent la clé de la base de données et les jetons des comptes.

## Étape par étape

<Tabs>
<TabItem label="Windows">

<Steps>

1. **Téléchargez l'installateur.** Sur [epistulamail.com](https://www.epistulamail.com), cliquez sur « Download EpistulaMail » et choisissez Windows. Le fichier fait environ 11 Mo.

2. **Vérifiez le fichier.** Dans PowerShell, dans le dossier du téléchargement :

   ```powershell
   (Get-FileHash .\EpistulaMail_1.1.0_x64-setup.exe).Hash
   ```

   Le résultat doit être identique au SHA-256 publié dans les [notes de version](https://github.com/elyosemite/epistulamail/releases/latest).

3. **Installez.** L'installateur n'est pas encore signé, donc Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur **Informations complémentaires** puis sur **Exécuter quand même**. Il s'installe pour votre utilisateur uniquement, sans droits d'administrateur.

4. **Connectez votre compte.** Ouvrez EpistulaMail et choisissez Gmail, Outlook ou [Autre](/fr/guia/contas/). La connexion se fait sur la page du fournisseur, dans votre navigateur ; votre mot de passe ne passe jamais par l'app.

5. **Lisez et cherchez.** Les e-mails les plus récents apparaissent en premier et le reste arrive en arrière-plan. Appuyez sur <kbd>/</kbd> et tapez `de: Ana tem:anexo` pour essayer la recherche par puces.

</Steps>

</TabItem>
<TabItem label="Linux">

<Steps>

1. **Téléchargez le paquet.** Sur [epistulamail.com](https://www.epistulamail.com), cliquez sur « Download EpistulaMail » et choisissez Linux. L'AppImage est un seul fichier ; le `.deb` est pour Debian et Ubuntu.

2. **Vérifiez le fichier.** Dans le terminal, dans le dossier du téléchargement :

   ```bash
   sha256sum EpistulaMail_1.1.0_amd64.AppImage
   ```

   Le résultat doit être identique au SHA-256 publié dans les [notes de version](https://github.com/elyosemite/epistulamail/releases/latest).

3. **Installez.** Pour l'AppImage :

   ```bash
   chmod +x EpistulaMail_1.1.0_amd64.AppImage
   ./EpistulaMail_1.1.0_amd64.AppImage
   ```

   Pour le `.deb` :

   ```bash
   sudo apt install ./EpistulaMail_1.1.0_amd64.deb
   ```

   L'app a besoin du Secret Service (GNOME Keyring ou KWallet) pour s'ouvrir. S'il n'est pas disponible, EpistulaMail affiche un avertissement et ne touche pas à vos données.

4. **Connectez votre compte.** Ouvrez EpistulaMail et choisissez Gmail, Outlook ou [Autre](/fr/guia/contas/). La connexion se fait sur la page du fournisseur, dans votre navigateur ; votre mot de passe ne passe jamais par l'app.

5. **Lisez et cherchez.** Les e-mails les plus récents apparaissent en premier et le reste arrive en arrière-plan. Appuyez sur <kbd>/</kbd> et tapez `de: Ana tem:anexo` pour essayer la recherche par puces.

</Steps>

</TabItem>
