EpistulaMail est distribué sous forme d'installateur Windows et d'AppImage et `.deb` pour Linux, publié à chaque version sur [GitHub](https://github.com/elyosemite/epistulamail/releases/latest) et derrière le bouton de téléchargement du [site](https://www.epistulamail.com).

## Prérequis

- Windows 10 ou 11, 64 bits, ou Linux, 64 bits.
- Sous Windows, WebView2, fourni avec Windows 11. Sous Windows 10, l'installateur le télécharge s'il manque.
- Sous Linux, le Secret Service (GNOME Keyring ou KWallet), qui garde la clé de la base de données et les jetons des comptes.
- Environ 100 Mo libres pour l'app, plus la place des messages que vous conservez.

## Installer sous Windows

<Steps>

1. Téléchargez `EpistulaMail_<version>_x64-setup.exe` sur le [site](https://www.epistulamail.com) ou dans la [dernière version](https://github.com/elyosemite/epistulamail/releases/latest).

2. Comparez le SHA-256 du fichier avec celui publié dans les notes de version :

   ```powershell
   (Get-FileHash .\EpistulaMail_1.0.2_x64-setup.exe).Hash
   ```

3. Ouvrez l'installateur. Sur l'avertissement SmartScreen, cliquez sur **Informations complémentaires** puis sur **Exécuter quand même**.

4. EpistulaMail est installé dans `%LOCALAPPDATA%\EpistulaMail`, pour votre utilisateur uniquement, avec un raccourci dans le menu Démarrer.

</Steps>

<Aside type="note" title="Pourquoi l'avertissement SmartScreen ?">
L'installateur n'a pas encore de certificat de signature de code. SmartScreen avertit pour les programmes sans signature ni historique de téléchargements. Vérifier le SHA-256 garantit que le fichier est bien celui qui a été publié.
</Aside>

## Installer sous Linux

<Steps>

1. Téléchargez `EpistulaMail_<version>_amd64.AppImage` ou `EpistulaMail_<version>_amd64.deb` sur le [site](https://www.epistulamail.com) ou dans la [dernière version](https://github.com/elyosemite/epistulamail/releases/latest).

2. Comparez le SHA-256 du fichier avec celui publié dans les notes de version :

   ```bash
   sha256sum EpistulaMail_1.0.2_amd64.AppImage
   ```

3. Pour l'AppImage, rendez-le exécutable et lancez-le :

   ```bash
   chmod +x EpistulaMail_1.0.2_amd64.AppImage
   ./EpistulaMail_1.0.2_amd64.AppImage
   ```

   Pour le `.deb`, installez-le avec le gestionnaire de paquets :

   ```bash
   sudo apt install ./EpistulaMail_1.0.2_amd64.deb
   ```

4. L'app a besoin du Secret Service (GNOME Keyring ou KWallet) pour s'ouvrir. S'il n'est pas disponible, EpistulaMail affiche un avertissement et ne modifie pas vos données.

</Steps>

<Aside type="note" title="Pourquoi le Secret Service ?">
Sous Linux, le coffre du système est le Secret Service. Il garde la clé de la base de données et les jetons de rafraîchissement des comptes, protégés par votre session. EpistulaMail ne stocke pas ces secrets dans un fichier ni dans la base de données.
</Aside>

## Nouvelles versions

Depuis la 1.0.2, quand une nouvelle version sort, une notification apparaît dans la cloche. Un clic montre ce qui a changé et, si vous confirmez, EpistulaMail la télécharge, vérifie la signature de la mise à jour, l'installe et se rouvre. Sous Linux, l'AppImage se met à jour ainsi ; le `.deb` est mis à jour par le gestionnaire de paquets de votre distribution. Voir [Mises à jour](/fr/guia/instalacao/atualizacoes/).
