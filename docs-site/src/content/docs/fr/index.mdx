## Par où commencer

Si c'est la première fois, suivez le **Démarrage rapide** : il installe EpistulaMail, connecte votre compte et montre la recherche. Si vous l'utilisez déjà, la **Documentation** détaille chaque fonction, avec ce qui se passe en coulisses et où se trouvent vos données.

Tout ce qui est ici concerne Windows 10 et 11 et Linux (64 bits). Sous Linux, le coffre du système est le Secret Service (GNOME Keyring ou KWallet). Les comptes Gmail et Microsoft personnels (Outlook.com, Hotmail et Live) peuvent se connecter ; les autres fournisseurs arrivent bientôt. Ouvrir d'anciennes archives d'e-mails fonctionne sans aucun compte.

## Ce qu'est EpistulaMail

- **À vous, sans piège.** Il n'y a ni compte EpistulaMail, ni cloud EpistulaMail, ni télémétrie. Aucun e-mail ne passe par un de nos serveurs.
- **Chiffré sur le disque.** Les messages sont dans une base de données chiffrée en AES-256, avec la clé dans le coffre du système (Gestionnaire d'identification sous Windows, Secret Service sous Linux).
- **Fonctionne hors ligne.** Ce qui a été téléchargé s'ouvre et se recherche sans internet.
- **Open source.** Tout est sur [GitHub](https://github.com/elyosemite/epistulamail).
