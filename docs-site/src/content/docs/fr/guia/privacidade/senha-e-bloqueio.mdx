Dans **Configurações → Privacidade** (Paramètres → Confidentialité) :

- **Mot de passe d'EpistulaMail** : la clé de la base dépend désormais de lui (Argon2id). Le mot de passe n'est stocké nulle part ; oublié, les messages de cet ordinateur ne s'ouvrent plus, mais ils restent sur le serveur.
- **Verrouiller après** : l'app ferme la base après un certain temps d'inactivité.
- **Verrouiller avec Windows** (Windows uniquement ; sous Linux, le verrouillage par inactivité continue et le verrouillage avec l'écran arrivera dans une prochaine version).
- **Garder moins** : effacer de l'ordinateur ce qui est hors de la période choisie.

<Aside type="note" title="Sous Linux">
