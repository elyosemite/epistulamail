- **Windows 10 ou 11, 64 bits**, ou **Linux, 64 bits**. macOS n'a pas encore d'installateur.
- **WebView2 sous Windows.** Fourni avec Windows 11 ; sous Windows 10, l'installateur le télécharge s'il manque.
- **Secret Service sous Linux** (GNOME Keyring ou KWallet), qui garde la clé de la base de données et les jetons des comptes.
- **De l'espace disque** pour les messages que vous choisissez de garder hors ligne.

Pour compiler depuis le code, voir [Compiler](/fr/guia/contribuir/compilar/).
