Sous Windows, désinstallez-le dans **Paramètres → Applications → EpistulaMail**.

Sous Linux, supprimez l'AppImage ou retirez le paquet `.deb` avec le gestionnaire de paquets de votre distribution (par exemple, `sudo apt remove epistulamail`).

Le désinstallateur supprime le programme. Pour effacer aussi les données :

1. Supprimez le dossier de données : sous Windows, `%APPDATA%\br.com.epistula.desktop` ; sous Linux, `~/.local/share/br.com.epistula.desktop`.
2. Dans le coffre du système, supprimez les éléments du service `epistula` : sous Windows, **Gestionnaire d'identification → Informations d'identification Windows** ; sous Linux, GNOME Keyring ou KWallet.
3. Si vous le souhaitez, retirez l'accès d'EpistulaMail sur [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

Les messages restent sur le serveur de votre messagerie.
