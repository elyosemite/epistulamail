Désinstallez-le depuis Windows, dans **Paramètres → Applications → EpistulaMail**.

Le désinstallateur supprime le programme. Pour effacer aussi les données :

1. Supprimez le dossier `%APPDATA%\br.com.epistula.desktop`.
2. Dans **Gestionnaire d'identification → Informations d'identification Windows**, supprimez les éléments du service `epistula`.
3. Si vous le souhaitez, retirez l'accès d'EpistulaMail sur [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

Les messages restent sur le serveur de votre messagerie.
