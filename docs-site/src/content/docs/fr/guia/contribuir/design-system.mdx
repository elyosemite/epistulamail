L'interface de l'app, du site et de cette documentation vient du design system du projet, dans [`design-system/`](https://github.com/elyosemite/epistulamail/tree/main/design-system) : tokens, typographie, couleurs et une page par composant. Les écrans montrés dans cette documentation utilisent le même HTML.

Une nouvelle pièce passe d'abord par un brouillon, stylé uniquement avec des tokens ; une fois approuvée, elle entre dans les pages du design system et dans l'app.
