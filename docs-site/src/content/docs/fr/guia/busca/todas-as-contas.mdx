Dans la barre des résultats, passez de **Esta conta** (ce compte) à **Todas as contas** (tous les comptes). Chaque résultat affiche l'avatar du compte, et ouvrir un résultat affiche le message dans son compte.

<AppPreview name="results" />

Les actions groupées (archiver, déplacer, supprimer) fonctionnent quand les résultats sélectionnés appartiennent au même compte.
