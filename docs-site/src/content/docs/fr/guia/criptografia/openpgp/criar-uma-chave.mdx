Dans **Configurações → Criptografia** (Paramètres → Chiffrement), créez une clé pour le compte. Il existe trois types :

- **Curve25519** : rapide, compacte et acceptée par la plupart des programmes. C'est celle recommandée.
- **RSA 4096** : pour échanger avec d'anciens programmes.
- **Post-quantique (expérimentale)** : ML-KEM-768 avec X25519. Peu de programmes la lisent encore.

<Aside type="caution" title="Faites une sauvegarde">
Sans sauvegarde, un ordinateur perdu emporte la clé, et les messages chiffrés pour elle ne s'ouvrent plus. Utilisez la sauvegarde protégée par mot de passe et gardez le fichier hors de l'ordinateur.
</Aside>
