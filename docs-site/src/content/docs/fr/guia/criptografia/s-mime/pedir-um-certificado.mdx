La paire de clés est créée sur votre ordinateur ; seule la demande part vers l'autorité de certification. Importez ensuite le certificat émis, ou un `.p12` que vous avez déjà.

Les certificats des personnes qui vous envoient des messages signés sont conservés. La confiance suit les racines du système.
