Quand vous choisissez Gmail, EpistulaMail ouvre la page de connexion de Google dans votre navigateur. Vous vous y connectez, autorisez l'accès et revenez à l'app.

EpistulaMail demande :

- **`https://mail.google.com/`** : lire, envoyer et organiser vos e-mails par IMAP et SMTP. C'est la seule autorisation Google qui donne accès à ces protocoles.
- **`openid`, `email` et `profile`** : votre adresse, votre nom et votre photo, pour afficher le compte.

Détails dans [Comment EpistulaMail utilise votre compte Google](https://www.epistulamail.com/conta-google) (en portugais).
