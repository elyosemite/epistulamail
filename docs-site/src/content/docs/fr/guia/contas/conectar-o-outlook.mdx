Quand vous choisissez Outlook, EpistulaMail ouvre la page de connexion de Microsoft dans votre navigateur. Vous vous connectez, vous autorisez et vous revenez à l'app. Cela vaut pour les comptes personnels Outlook.com, Hotmail et Live.

EpistulaMail demande seulement :

- **`Mail.ReadWrite`** : lire et organiser vos e-mails par Microsoft Graph.
- **`Mail.Send`** : envoyer des e-mails par Microsoft Graph.
- **`User.Read` et `profile`** : votre nom, votre adresse et votre photo de profil, pour afficher le compte.
- **`openid`, `email` et `offline_access`** : l'identité du compte et l'autorisation de garder la connexion sans redemander de connexion à chaque synchronisation.

Il ne demande ni contacts, ni calendrier, ni fichiers, ni OneDrive, ni profil au-delà de l'adresse et du nom. Votre mot de passe Microsoft ne passe jamais par EpistulaMail.

Le refresh token se trouve dans le coffre du système (Gestionnaire d'identification sous Windows, Secret Service sous Linux), avec le même soin que les comptes Google : jamais dans la base en clair, jamais dans un fichier, jamais dans un journal. Pour révoquer l'accès, utilisez [account.live.com/consent/Manage](https://account.live.com/consent/Manage).
