Depuis le menu du compte, **Sair** (se déconnecter) supprime le jeton local et révoque l'accès auprès de Google. Pour les comptes Microsoft, le jeton local est supprimé ; révoquez l'accès sur [account.live.com/consent/Manage](https://account.live.com/consent/Manage) ou auprès de l'administrateur Microsoft 365. Vous choisissez si les messages déjà téléchargés restent sur l'ordinateur (pour continuer à lire et chercher) ou sont effacés.
