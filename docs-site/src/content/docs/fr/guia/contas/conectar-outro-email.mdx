Utilisez cette option si votre adresse n'est pas Gmail ou Outlook, ou si vous voulez saisir les serveurs vous-même. EpistulaMail utilise IMAP pour recevoir et SMTP pour envoyer.

<Steps>

1. Dans **Ajouter un compte**, choisissez **Autre**.
2. Remplissez l'**Entrée** : serveur, port, sécurité de la connexion, authentification, utilisateur et mot de passe. Les valeurs les plus courantes sont `993` avec SSL/TLS ou `143` avec STARTTLS.
3. Remplissez la **Sortie** avec le serveur SMTP. Les valeurs les plus courantes sont `465` avec SSL/TLS ou `587` avec STARTTLS. Si les identifiants sont ceux de l'entrée, laissez **Utiliser les identifiants de l'entrée** activé.
4. Cliquez sur **Tester la connexion**. L'application se connecte à l'entrée, vérifie la Boîte de réception et se connecte à la sortie sans envoyer de message.
5. Une fois les deux tests réussis, cliquez sur **Connecter**.

</Steps>

Le compte n'est enregistré qu'après la réussite des tests d'entrée et de sortie. Si le serveur refuse l'utilisateur ou le mot de passe, le message indique quel côté a échoué et la configuration n'est pas enregistrée.

<Aside type="note" title="Mot de passe d'application">
Certains fournisseurs exigent un mot de passe d'application au lieu du mot de passe normal, surtout lorsque la validation en deux étapes est activée. Générez-le sur le site du fournisseur et utilisez-le ici. Gmail et Outlook doivent être connectés via leurs propres cartes, avec OAuth.
</Aside>

EpistulaMail n'accepte que **SSL/TLS** ou **STARTTLS** ; il n'y a pas d'option « sans sécurité ». Le certificat est toujours vérifié. Le mot de passe est conservé dans le coffre du système (Gestionnaire d'identifiants sous Windows, Secret Service sous Linux), jamais dans la base en clair, dans un fichier ou dans un journal. Avec le mot de passe Epistula activé, il est aussi chiffré par celui-ci.

Dans cette version, le compte manuel reçoit et envoie avec un **mot de passe normal**. Le mot de passe chiffré (CRAM-MD5), Kerberos/GSSAPI, NTLM, OAuth2 pour les comptes manuels et POP3 arriveront dans de prochaines mises à jour.
