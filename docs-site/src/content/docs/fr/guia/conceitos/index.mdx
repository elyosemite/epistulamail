## Comment fonctionne EpistulaMail

EpistulaMail est un programme de bureau construit avec Tauri (Rust et React). Il communique directement avec le serveur de votre messagerie, avec les protocoles habituels :

- **IMAP** pour télécharger et organiser les messages ;
- **SMTP** pour envoyer ;
- **OAuth** pour la connexion, sans que votre mot de passe passe par l'app.

Ce qui arrive est stocké dans une base de données locale (SQLCipher, chiffrée en AES-256). La liste, la lecture et la recherche lisent cette base : elles s'ouvrent vite et fonctionnent hors ligne. Les changements que vous faites (déplacer, archiver, marquer comme lu) sont ensuite envoyés au serveur.

Il n'y a pas de serveur EpistulaMail au milieu : aucun message, objet ou adresse ne passe par nous.

## Où se trouvent vos données

| Quoi | Où |
|---|---|
| Le programme | Windows : `%LOCALAPPDATA%\EpistulaMail` ; Linux : l'AppImage ou le paquet `.deb` |
| Base des messages et paramètres | Windows : `%APPDATA%\br.com.epistula.desktop` ; Linux : `~/.local/share/br.com.epistula.desktop` |
| Clé de la base et accès aux comptes | Coffre du système : Gestionnaire d'identification sous Windows, Secret Service sous Linux (GNOME Keyring ou KWallet), éléments `epistula` |

La base est chiffrée : un fichier copié, un portable perdu ou un disque jeté ne révèlent rien sans la clé. La clé se trouve dans le coffre du système, protégée par votre session ; avec le mot de passe d'EpistulaMail activé, elle dépend aussi de ce mot de passe.
