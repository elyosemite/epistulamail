| Quoi | Où |
|---|---|
| Le programme | `%LOCALAPPDATA%\EpistulaMail` |
| Base des messages et paramètres | `%APPDATA%\br.com.epistula.desktop` |
| Clé de la base et accès aux comptes | Gestionnaire d'identification de Windows, éléments `epistula` |

La base est chiffrée : un fichier copié, un portable perdu ou un disque jeté ne révèlent rien sans la clé. La clé se trouve dans le coffre d'identifiants de Windows, protégée par votre session ; avec le mot de passe d'EpistulaMail activé, elle dépend aussi de ce mot de passe.
