Une conversation apparaît comme une ligne dans la liste. Ouverte, chaque réponse devient une carte ; les non lues restent ouvertes et le texte cité se cache derrière un « … ».

<AppPreview name="conversation" />

Le HTML des messages est nettoyé avant d'être affiché, sans scripts. Les images externes restent bloquées jusqu'à ce que vous les autorisiez pour ce message, car elles indiqueraient à l'expéditeur que vous avez ouvert l'e-mail.
