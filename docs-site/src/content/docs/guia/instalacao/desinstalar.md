---
title: "Desinstalar"
description: "Remover o EpistulaMail e, se quiser, os dados."
sidebar:
  order: 3
---

Desinstale pelo Windows, em **Configurações → Aplicativos → EpistulaMail**.

O desinstalador remove o programa. Para apagar também os dados:

1. Apague a pasta `%APPDATA%\br.com.epistula.desktop`.
2. No **Gerenciador de Credenciais → Credenciais do Windows**, remova os itens do serviço `epistula`.
3. Se quiser, remova o acesso do EpistulaMail em [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

As mensagens continuam no servidor do seu e-mail.
