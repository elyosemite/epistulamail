- **Windows 10 ou 11, 64 bits**, ou **Linux, 64 bits**. O macOS ainda não tem instalador.
- **WebView2 no Windows.** Já vem no Windows 11; no Windows 10, o instalador baixa se faltar.
- **Secret Service no Linux** (GNOME Keyring ou KWallet), que guarda a chave do banco e os tokens das contas.
- **Espaço em disco** para as mensagens que você escolher guardar sem conexão.
