description: "O que o computador precisa para rodar o EpistulaMail."

  order: 1
---

- **Windows 10 ou 11, 64 bits.** Outras plataformas ainda não têm instalador.
- **WebView2.** Já vem no Windows 11; no Windows 10, o instalador baixa se faltar.
- **Espaço em disco** para as mensagens que você escolher guardar sem conexão.

Para compilar a partir do código, veja [Compilar](/guia/contribuir/compilar/).
