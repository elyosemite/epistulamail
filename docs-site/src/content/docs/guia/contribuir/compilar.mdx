Requisitos: Node.js 24, pnpm 10 e Rust 1.88 ou mais novo. O SQLCipher compila o próprio OpenSSL, então o build precisa de Perl, compilador C e `make` nas duas plataformas.

<Tabs>
<TabItem label="Windows">

O Perl portátil do Windows é baixado uma vez pelo script. Ele fica em `.tools/` e o script define `OPENSSL_SRC_PERL` para a sessão e para o ambiente do usuário.

```powershell
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
./scripts/setup-build-tools.ps1
pnpm tauri dev
pnpm tauri build
```

</TabItem>
<TabItem label="Linux">

No Debian e no Ubuntu, instale as bibliotecas do Tauri, o libdbus do Secret Service e o Perl:

```bash
sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev \
  libdbus-1-dev libxdo-dev build-essential pkg-config perl
```

Depois:

```bash
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
pnpm tauri dev
pnpm tauri build
```

</TabItem>
</Tabs>

`pnpm tauri dev` roda em desenvolvimento; `pnpm tauri build` gera o instalador no Windows e o AppImage e o `.deb` no Linux. O build de desenvolvimento usa uma pasta de dados e itens no cofre só dele, então não mexe no EpistulaMail instalado. Para conectar contas no desenvolvimento, crie os seus clientes OAuth e ponha no `.env` (veja o README).
