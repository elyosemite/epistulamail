A interface do app, do site e desta documentação vem do design system do projeto, em [`design-system/`](https://github.com/elyosemite/epistulamail/tree/main/design-system): tokens, tipografia, cores e uma página para cada componente.

Peça nova vai primeiro para um rascunho, com estilos só de tokens; depois de aprovada, entra nas páginas do DS e no app.
