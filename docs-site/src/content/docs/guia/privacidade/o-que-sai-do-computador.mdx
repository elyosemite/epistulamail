- **O seu provedor de e-mail**: login, IMAP, SMTP e o cancelamento do acesso ao sair.
- **Servidores de chaves OpenPGP**: só quando você pede para buscar uma chave.
- **Imagens externas de um e-mail**: só quando você libera naquela mensagem.
- **GitHub**: a verificação de versão nova (o arquivo `latest.json` da última release).

Não há telemetria, relatório de erro nem servidor do EpistulaMail. A [política de privacidade](https://www.epistulamail.com/privacidade) tem os detalhes.
