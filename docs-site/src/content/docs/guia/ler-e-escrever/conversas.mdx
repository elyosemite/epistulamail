Uma conversa aparece como uma linha na lista. Aberta, cada resposta vira um cartão; as não lidas ficam abertas e o texto citado fica atrás de um "…".

O HTML das mensagens é limpo antes de ser mostrado, sem scripts. As imagens externas ficam bloqueadas até você liberar naquela mensagem, porque elas avisariam ao remetente que você abriu o e-mail.
