---
title: "Sair de uma conta"
description: "O que acontece ao sair, e como apagar as mensagens do computador."
sidebar:
  order: 3
---

Pelo menu da conta, **Sair** cancela o acesso junto ao Google. Você escolhe se as mensagens já baixadas ficam no computador (para continuar lendo e buscando) ou se são apagadas.
