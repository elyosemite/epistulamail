Cada conta aparece na coluna da esquerda, com nome, cor e foto próprios. Um clique troca de conta; o atalho <kbd>Ctrl</kbd> + número também.

A busca pode olhar uma conta ou todas de uma vez. As regras e a sincronização são de cada conta.
