Ao escolher o Outlook, o EpistulaMail abre a página de login da Microsoft no seu navegador. Você entra, autoriza e volta para o app. Vale para contas pessoais Outlook.com, Hotmail e Live.

O EpistulaMail pede só:

- **`Mail.ReadWrite`**: ler e organizar os seus e-mails pelo Microsoft Graph.
- **`Mail.Send`**: enviar e-mails pelo Microsoft Graph.
- **`User.Read` e `profile`**: o seu nome, o endereço e a foto do perfil, para mostrar a conta.
- **`openid`, `email` e `offline_access`**: a identidade da conta e a permissão para manter a conexão sem pedir login a cada sincronização.

O app não pede contatos, calendário, arquivos, OneDrive nem perfil além do endereço e do nome. A senha da Microsoft nunca passa pelo EpistulaMail.

O refresh token fica no cofre do sistema (Gerenciador de Credenciais no Windows, Secret Service no Linux), com o mesmo cuidado das contas Google: nunca no banco em texto, nunca em arquivo, nunca no log. Para revogar o acesso, use [account.live.com/consent/Manage](https://account.live.com/consent/Manage).
