Ao escolher o Outlook, o EpistulaMail abre a página de login da Microsoft no seu navegador. Você entra, autoriza e volta para o app. Vale para Outlook.com, Hotmail e Microsoft 365.

O EpistulaMail pede só:

- **`https://graph.microsoft.com/Mail.ReadWrite`**: ler e organizar os seus e-mails pelo Microsoft Graph.
- **`https://graph.microsoft.com/Mail.Send`**: enviar e-mails pelo Microsoft Graph.
- **`openid`, `email` e `offline_access`**: o seu endereço e nome, para mostrar a conta, e a permissão para manter a conexão sem pedir login a cada sincronização.

O app não pede contatos, calendário, arquivos, OneDrive nem perfil além do endereço e do nome. A senha da Microsoft nunca passa pelo EpistulaMail.

<Aside type="note" title="Contas de empresa ou escola">
Em Microsoft 365, o administrador do tenant pode precisar conceder consentimento para as permissões do Microsoft Graph. Se a conexão for recusada, fale com o administrador.
</Aside>

O refresh token fica no cofre do sistema (Gerenciador de Credenciais no Windows, Secret Service no Linux), com o mesmo cuidado das contas Google: nunca no banco em texto, nunca em arquivo, nunca no log. Para revogar o acesso, use [account.live.com/consent/Manage](https://account.live.com/consent/Manage) ou a página de consentimentos do Microsoft 365.
