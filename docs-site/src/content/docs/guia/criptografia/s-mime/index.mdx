O par de chaves é criado no seu computador; só o pedido vai para a autoridade certificadora. Depois, importe o certificado emitido, ou importe um `.p12` que você já tenha.

Os certificados de quem manda mensagens assinadas para você são guardados. A confiança segue as raízes do sistema.
