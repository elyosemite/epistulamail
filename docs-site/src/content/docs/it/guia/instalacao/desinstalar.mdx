Disinstallalo da Windows, in **Impostazioni → App → EpistulaMail**.

Il programma di disinstallazione rimuove il programma. Per cancellare anche i dati:

1. Elimina la cartella `%APPDATA%\br.com.epistula.desktop`.
2. In **Gestione credenziali → Credenziali di Windows**, rimuovi gli elementi del servizio `epistula`.
3. Se vuoi, revoca l'accesso di EpistulaMail su [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

I messaggi restano sul server della tua posta.
