- **Windows 10 o 11, 64 bit**, o **Linux, 64 bit**. macOS non ha ancora un programma di installazione.
- **WebView2 su Windows.** È incluso in Windows 11; su Windows 10, il programma di installazione lo scarica se manca.
- **Secret Service su Linux** (GNOME Keyring o KWallet), che conserva la chiave del database e i token degli account.
- **Spazio su disco** per i messaggi che scegli di conservare offline.

Per compilare dal codice, vedi [Compilare](/it/guia/contribuir/compilar/).
