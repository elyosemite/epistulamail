- **Windows 10 o 11, 64 bit.** Le altre piattaforme non hanno ancora un programma di installazione.
- **WebView2.** È incluso in Windows 11; su Windows 10, il programma di installazione lo scarica se manca.
- **Spazio su disco** per i messaggi che scegli di conservare offline.
