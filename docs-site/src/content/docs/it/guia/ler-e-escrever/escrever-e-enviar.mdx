Scrivi una nuova email, rispondi, rispondi a tutti o inoltra. Le bozze vengono salvate cifrate.

Dopo **Enviar** (invia), hai qualche secondo per **Desfazer** (annulla): l'email parte solo allo scadere del tempo.
