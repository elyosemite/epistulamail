| Cosa | Dove |
|---|---|
| Il programma | Windows: `%LOCALAPPDATA%\EpistulaMail`; Linux: l'AppImage o il pacchetto `.deb` |
| Database dei messaggi e impostazioni | Windows: `%APPDATA%\br.com.epistula.desktop`; Linux: `~/.local/share/br.com.epistula.desktop` |
| Chiave del database e accesso agli account | Vault del sistema: Gestione credenziali su Windows, Secret Service su Linux (GNOME Keyring o KWallet), elementi `epistula` |

Il database è cifrato: un file copiato, un portatile perso o un disco buttato non rivelano nulla senza la chiave. La chiave sta nel vault del sistema, protetta dalla tua sessione; con la password di EpistulaMail attiva, dipende anche da questa.
