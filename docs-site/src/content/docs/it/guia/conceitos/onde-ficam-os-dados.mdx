| Cosa | Dove |
|---|---|
| Il programma | `%LOCALAPPDATA%\EpistulaMail` |
| Database dei messaggi e impostazioni | `%APPDATA%\br.com.epistula.desktop` |
| Chiave del database e accesso agli account | Gestione credenziali di Windows, elementi `epistula` |

Il database è cifrato: un file copiato, un portatile perso o un disco buttato non rivelano nulla senza la chiave. La chiave sta nel vault delle credenziali di Windows, protetta dalla tua sessione; con la password di EpistulaMail attiva, dipende anche da questa.
