Dal menu dell'account, **Sair** (esci) cancella il token locale e revoca l'accesso presso Google. Per gli account Microsoft, il token locale viene cancellato; revoca l'accesso su [account.live.com/consent/Manage](https://account.live.com/consent/Manage) o con l'amministratore di Microsoft 365. Scegli tu se i messaggi già scaricati restano sul computer (per continuare a leggere e cercare) o vengono cancellati.
