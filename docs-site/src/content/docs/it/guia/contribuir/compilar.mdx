Requisiti: Node.js 24, pnpm 10 e Rust 1.88 o più recente. SQLCipher compila il proprio OpenSSL, quindi la build ha bisogno di Perl, un compilatore C e `make` su entrambe le piattaforme.

<Tabs>
<TabItem label="Windows">

Il Perl portatile di Windows viene scaricato una volta dallo script. Sta in `.tools/` e lo script imposta `OPENSSL_SRC_PERL` per la sessione e per l'ambiente dell'utente.

```powershell
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
./scripts/setup-build-tools.ps1
pnpm tauri dev
pnpm tauri build
```

</TabItem>
<TabItem label="Linux">

Su Debian e Ubuntu, installa le librerie di Tauri, la libdbus del Secret Service e Perl:

```bash
sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev \
  libdbus-1-dev libxdo-dev build-essential pkg-config perl
```

Poi:

```bash
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
pnpm tauri dev
pnpm tauri build
```

</TabItem>
</Tabs>

`pnpm tauri dev` lo esegue in sviluppo; `pnpm tauri build` genera il programma di installazione su Windows e l'AppImage e il `.deb` su Linux. La build di sviluppo usa una cartella dati e voci nel vault tutte sue, quindi non tocca l'EpistulaMail installato. Per collegare account in sviluppo, crea i tuoi client OAuth e mettili in `.env` (vedi il README).
