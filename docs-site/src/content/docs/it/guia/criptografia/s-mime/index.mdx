La coppia di chiavi viene creata sul tuo computer; solo la richiesta va all'autorità di certificazione. Poi importa il certificato emesso, oppure un `.p12` che hai già.

I certificati di chi ti invia messaggi firmati vengono conservati. La fiducia segue le radici del sistema.
