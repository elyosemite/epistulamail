Con **Salvar busca** (salva ricerca), dalle un nome. La ricerca compare nella colonna delle cartelle, in un gruppo proprio, con le non lette. Il clic destro la elimina.

<AppPreview name="saved" width={18} />

Nei risultati, **Aplicar regra…** (applica regola) applica una delle tue regole ai messaggi selezionati, con anteprima prima e "Annulla" dopo.
