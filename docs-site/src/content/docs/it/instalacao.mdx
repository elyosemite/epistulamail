EpistulaMail è distribuito come programma di installazione per Windows e come AppImage e `.deb` per Linux, pubblicato a ogni versione su [GitHub](https://github.com/elyosemite/epistulamail/releases/latest) e tramite il pulsante di download del [sito](https://www.epistulamail.com).

## Requisiti

- Windows 10 o 11, 64 bit, o Linux, 64 bit. macOS non ha ancora un programma di installazione.
- Su Windows, WebView2, già incluso in Windows 11. Su Windows 10, il programma di installazione lo scarica se manca.
- Su Linux, il Secret Service (GNOME Keyring o KWallet), che conserva la chiave del database e i token degli account.
- Circa 100 MB liberi per l'app, più lo spazio per i messaggi che conservi.

Per compilare dal codice, vedi [Compilare](/it/guia/contribuir/compilar/).

## Installare su Windows

<Steps>

1. Scarica `EpistulaMail_<versione>_x64-setup.exe` dal [sito](https://www.epistulamail.com) o dall'[ultima versione](https://github.com/elyosemite/epistulamail/releases/latest).

2. Confronta lo SHA-256 del file con quello pubblicato nelle note di rilascio:

   ```powershell
   (Get-FileHash .\EpistulaMail_1.1.0_x64-setup.exe).Hash
   ```

3. Apri il programma di installazione. Sull'avviso di SmartScreen, fai clic su **Ulteriori informazioni** e poi su **Esegui comunque**.

4. EpistulaMail viene installato in `%LOCALAPPDATA%\EpistulaMail`, solo per il tuo utente, con un collegamento nel menu Start.

</Steps>

<Aside type="note" title="Perché l'avviso di SmartScreen?">
Il programma di installazione non ha ancora un certificato di firma del codice. SmartScreen avvisa per i programmi senza firma e senza cronologia di download. Verificare lo SHA-256 garantisce che il file è quello pubblicato.
</Aside>

## Installare su Linux

<Steps>

1. Scarica `EpistulaMail_<versione>_amd64.AppImage` o `EpistulaMail_<versione>_amd64.deb` dal [sito](https://www.epistulamail.com) o dall'[ultima versione](https://github.com/elyosemite/epistulamail/releases/latest).

2. Confronta lo SHA-256 del file con quello pubblicato nelle note di rilascio:

   ```bash
   sha256sum EpistulaMail_1.1.0_amd64.AppImage
   ```

3. Per l'AppImage, rendilo eseguibile e aprilo:

   ```bash
   chmod +x EpistulaMail_1.1.0_amd64.AppImage
   ./EpistulaMail_1.1.0_amd64.AppImage
   ```

   Per il `.deb`, installalo con il gestore di pacchetti:

   ```bash
   sudo apt install ./EpistulaMail_1.1.0_amd64.deb
   ```

4. L'app ha bisogno del Secret Service (GNOME Keyring o KWallet) per aprirsi. Se non è disponibile, EpistulaMail mostra un avviso e non modifica i tuoi dati.

</Steps>

<Aside type="note" title="Perché il Secret Service?">
Su Linux, il vault del sistema è il Secret Service. Conserva la chiave del database e i refresh token degli account, protetti dalla tua sessione. EpistulaMail non salva questi segreti in un file né nel database.
</Aside>

## Nuove versioni

Dalla 1.0.2, EpistulaMail controlla se c'è una nuova versione all'apertura e ogni 6 ore.

1. Quando c'è, compare **una volta** nella campanella: "Nova versão do EpistulaMail" (nuova versione di EpistulaMail).
2. Il clic apre la conferma con le novità.
3. Con **Atualizar e reiniciar** (aggiorna e riavvia), l'app scarica la nuova versione, ne verifica la firma, si chiude, la installa e si riapre.

<AppPreview name="update" />

Account, messaggi e impostazioni restano. Un file senza la firma corretta viene rifiutato, quindi si installano solo le versioni pubblicate dal progetto.

Su Linux, l'AppImage si aggiorna allo stesso modo. Il `.deb` viene aggiornato dal gestore di pacchetti della tua distribuzione, non dalla campanella dell'app.

Se sei sulla 1.0.0 o 1.0.1, installa la 1.0.2 a mano una volta.

## Disinstallare

Su Windows, disinstallalo in **Impostazioni → App → EpistulaMail**.

Su Linux, elimina l'AppImage o rimuovi il pacchetto `.deb` con il gestore di pacchetti della tua distribuzione (per esempio, `sudo apt remove epistulamail`).

Il programma di disinstallazione rimuove il programma. Per cancellare anche i dati:

1. Elimina la cartella dei dati: su Windows, `%APPDATA%\br.com.epistula.desktop`; su Linux, `~/.local/share/br.com.epistula.desktop`.
2. Nel vault del sistema, rimuovi gli elementi del servizio `epistula`: su Windows, **Gestione credenziali → Credenziali di Windows**; su Linux, GNOME Keyring o KWallet.
3. Se vuoi, revoca l'accesso di EpistulaMail su [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

I messaggi restano sul server della tua posta.
