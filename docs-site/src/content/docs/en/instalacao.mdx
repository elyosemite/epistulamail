EpistulaMail ships as a Windows installer and as an AppImage and `.deb` for Linux, published with each release on [GitHub](https://github.com/elyosemite/epistulamail/releases/latest) and behind the download button on the [website](https://www.epistulamail.com).

## Requirements

- Windows 10 or 11, 64-bit, or Linux, 64-bit. macOS does not have an installer yet.
- On Windows, WebView2, which comes with Windows 11. On Windows 10, the installer downloads it if missing.
- On Linux, the Secret Service (GNOME Keyring or KWallet), which stores the database key and account tokens.
- About 100 MB free for the app, plus the space for the messages you keep.

To build from source, see [Building](/en/guia/contribuir/compilar/).

## Install on Windows

<Steps>

1. Download `EpistulaMail_<version>_x64-setup.exe` from the [website](https://www.epistulamail.com) or the [latest release](https://github.com/elyosemite/epistulamail/releases/latest).

2. Compare the file's SHA-256 with the one published in the release notes:

   ```powershell
   (Get-FileHash .\EpistulaMail_1.1.0_x64-setup.exe).Hash
   ```

3. Open the installer. On the SmartScreen warning, click **More info** and then **Run anyway**.

4. EpistulaMail is installed in `%LOCALAPPDATA%\EpistulaMail`, for your user only, with a Start menu shortcut.

</Steps>

<Aside type="note" title="Why the SmartScreen warning?">
The installer does not have a code-signing certificate yet. SmartScreen warns about programs with no signature and no download history. Checking the SHA-256 guarantees the file is the one that was published.
</Aside>

## Install on Linux

<Steps>

1. Download `EpistulaMail_<version>_amd64.AppImage` or `EpistulaMail_<version>_amd64.deb` from the [website](https://www.epistulamail.com) or the [latest release](https://github.com/elyosemite/epistulamail/releases/latest).

2. Compare the file's SHA-256 with the one published in the release notes:

   ```bash
   sha256sum EpistulaMail_1.1.0_amd64.AppImage
   ```

3. For the AppImage, make it executable and run it:

   ```bash
   chmod +x EpistulaMail_1.1.0_amd64.AppImage
   ./EpistulaMail_1.1.0_amd64.AppImage
   ```

   For the `.deb`, install it with the package manager:

   ```bash
   sudo apt install ./EpistulaMail_1.1.0_amd64.deb
   ```

4. The app needs the Secret Service (GNOME Keyring or KWallet) to open. If it is not available, EpistulaMail shows a message and does not change your data.

</Steps>

<Aside type="note" title="Why the Secret Service?">
On Linux, the system vault is the Secret Service. It holds the database key and the account refresh tokens, protected by your session. EpistulaMail does not store those secrets in a file or in the database.
</Aside>

## New versions

Since 1.0.2, EpistulaMail checks for a new version when it opens and every 6 hours.

1. When there is one, it shows up **once** in the bell: "Nova versão do EpistulaMail" (new EpistulaMail version).
2. Clicking it opens the confirmation with what changed.
3. With **Atualizar e reiniciar** (update and restart), the app downloads the new version, checks its signature, closes, installs it and opens again.

<AppPreview name="update" />

Your accounts, messages and settings stay. A file without the right signature is rejected, so only versions published by the project get installed.

On Linux, the AppImage updates the same way. The `.deb` is updated by your distribution's package manager, not by the app's bell.

If you are on 1.0.0 or 1.0.1, install 1.0.2 by hand once.

## Uninstall

On Windows, uninstall it under **Settings → Apps → EpistulaMail**.

On Linux, delete the AppImage or remove the `.deb` package with your distribution's package manager (for example, `sudo apt remove epistulamail`).

The uninstaller removes the program. To also erase the data:

1. Delete the data folder: on Windows, `%APPDATA%\br.com.epistula.desktop`; on Linux, `~/.local/share/br.com.epistula.desktop`.
2. In the system vault, remove the `epistula` service entries: on Windows, **Credential Manager → Windows Credentials**; on Linux, GNOME Keyring or KWallet.
3. If you want, remove EpistulaMail's access at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

Your messages stay on your email server.
