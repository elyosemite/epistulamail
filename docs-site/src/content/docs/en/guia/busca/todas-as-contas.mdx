In the results bar, switch **Esta conta** (this account) to **Todas as contas** (all accounts). Each result shows the account's avatar, and opening a result shows the message in its own account.

<AppPreview name="results" />

Bulk actions (archive, move, delete) work when the selected results belong to the same account.
