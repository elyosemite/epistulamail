Press <kbd>/</kbd> to jump to search. What you type turns into chips you can edit and remove. The operators are in Portuguese, like the app's interface:

<AppPreview name="search" />

| Type | Becomes |
|---|---|
| `de: Ana` | who sent it (also `from:`) |
| `para:`, `cc:`, `com:` | recipient, copy, any of those (also `to:`) |
| `depois:2026-01-01`, `antes:31/03/2026`, `em:2025` | date range |
| `tem:anexo` | with attachment |
| `é:não-lida`, `é:estrela` | unread, starred |
| `na: Arquivo` | in a folder |

Two chips with the same role add up ("from Ana or from Bruno"); different roles apply together. <kbd>Backspace</kbd> in an empty field selects the last chip; pressing it again removes it.

Search runs on the messages stored on your computer, in every folder, and works offline.
