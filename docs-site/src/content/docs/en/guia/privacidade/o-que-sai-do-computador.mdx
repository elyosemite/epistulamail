- **Your email provider**: sign-in, IMAP, SMTP and revoking access when you sign out.
- **OpenPGP key servers**: only when you ask to look up a key.
- **Remote images in an email**: only when you allow them for that message.
- **GitHub**: the new-version check (the `latest.json` file of the latest release).

There is no telemetry, no crash reporting and no EpistulaMail server. The [privacy policy](https://www.epistulamail.com/privacidade) (in Portuguese) has the details.
