- **Your email provider (Google or Microsoft)**: sign-in; IMAP and SMTP on Google; Microsoft Graph on Microsoft; and revoking access when you sign out.
- **The server you enter**: in manual accounts, EpistulaMail talks to the IMAP and SMTP servers you configured.
- **OpenPGP key servers**: only when you ask to look up a key.
- **Remote images in an email**: only when you allow them for that message.
- **GitHub**: the new-version check (the `latest.json` file of the latest release).

On Google, EpistulaMail asks for `https://mail.google.com/`, `openid`, `email` and `profile`. On Microsoft, it asks for `Mail.ReadWrite`, `Mail.Send`, `User.Read`, `openid`, `profile`, `email` and `offline_access`. It does not ask for contacts, calendar, files or OneDrive.

On Linux, the app also talks to the Secret Service over the local session bus (D-Bus) to store and read the database key and account tokens. That stays on your computer and is not a network connection.

There is no telemetry, no crash reporting and no EpistulaMail server. The [privacy policy](https://www.epistulamail.com/privacidade) (in Portuguese) has the details.
