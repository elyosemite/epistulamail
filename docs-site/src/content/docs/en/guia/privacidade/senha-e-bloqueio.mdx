In **Configurações → Privacidade** (Settings → Privacy):

- **EpistulaMail password**: the database key starts depending on it (Argon2id). The password is not stored anywhere; if you forget it, the messages on this computer will not open, but they stay on the server.
- **Lock after**: the app closes the database after a period without use.
- **Lock together with Windows** (Windows only; on Linux, the idle lock keeps working and locking with the screen is coming in a future version).
- **Keep less**: erase from the computer what falls outside the chosen period.
