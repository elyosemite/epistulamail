The interface of the app, the website and this documentation comes from the project's design system, in [`design-system/`](https://github.com/elyosemite/epistulamail/tree/main/design-system): tokens, typography, colors and a page for each component. The screens shown in this documentation use the same HTML.

A new piece first goes into a draft, styled only with tokens; once approved, it moves into the design system pages and the app.
