| What | Where |
|---|---|
| The program | Windows: `%LOCALAPPDATA%\EpistulaMail`; Linux: the AppImage or the `.deb` package |
| Message database and settings | Windows: `%APPDATA%\br.com.epistula.desktop`; Linux: `~/.local/share/br.com.epistula.desktop` |
| Database key and account access | System vault: Windows Credential Manager, Linux Secret Service (GNOME Keyring or KWallet), `epistula` items |

The database is encrypted: a copied file, a lost laptop or a discarded drive reveals nothing without the key. The key lives in the system vault, protected by your session; with the EpistulaMail password on, it also depends on the password.
