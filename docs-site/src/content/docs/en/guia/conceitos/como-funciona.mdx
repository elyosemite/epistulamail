EpistulaMail is a desktop program built with Tauri (Rust and React). It talks straight to your email server, using the usual protocols:

- **IMAP** to download and organize messages;
- **SMTP** to send;
- **OAuth** to sign in, without your password going through the app.

What arrives is stored in a local database (SQLCipher, encrypted with AES-256). The list, the reader and the search read from that database, so they open fast and work offline. The changes you make (move, archive, mark as read) are then sent to the server.

There is no EpistulaMail server in the middle: no message, subject or address goes through us.
