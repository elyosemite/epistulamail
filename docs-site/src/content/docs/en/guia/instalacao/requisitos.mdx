- **Windows 10 or 11, 64-bit.** Other platforms do not have an installer yet.
- **WebView2.** It comes with Windows 11; on Windows 10, the installer downloads it if missing.
- **Disk space** for the messages you choose to keep offline.

To build from source, see [Building](/en/guia/contribuir/compilar/).
