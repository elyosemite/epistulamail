On the first screen, or with the **+** in the account column, choose **Abrir arquivo de e-mail** (open email archive), or drop the file on the window.

| Source | Format |
|---|---|
| Google Takeout | `.mbox` (labels become labels) |
| Outlook | `.pst` and `.msg` |
| Thunderbird | the profile folders |
| Apple Mail | exported `.mbox` and `.emlx` |
| Any program | `.eml` and Maildir |

The file is read on your computer and copied into the encrypted database; the original is only read. Before importing you see the folders and how much space it will take; afterwards, how many came in, how many were duplicates and how many failed.
