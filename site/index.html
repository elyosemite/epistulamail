Uma caixa de entrada que é só sua

Cada mensagem que você abre fica no seu disco, num banco cifrado com AES-256. Se a rede cair, a caixa continua lá.

Recursos

  • Leitura sem conexão
  • Conversas em cartões
  • Imagens espiãs bloqueadas
  • Notificações sem conteúdo

Criptografia de ponta a ponta, sem complicar

OpenPGP e S/MIME no mesmo composer: o cadeado liga sozinho quando todos os destinatários têm chave ou certificado.

Recursos

  • Chaves Curve25519 e pós-quânticas
  • Certificados S/MIME com a cadeia à vista
  • Assunto protegido
  • Selos de assinatura na leitura

Protegido até de quem usa o seu Windows

Com a senha do Epistula, a chave do banco é protegida por Argon2id e sai da memória quando o Windows bloqueia a tela.

Recursos

  • Bloqueio automático
  • Logs sem conteúdo, testados
  • Chaves longe da interface
  • Modelo de ameaças público

Quer contribuir?

O Epistula é código aberto. Dá para clonar o repositório, rodar o app na sua máquina e mandar uma melhoria, um relato de problema ou uma ideia de interface.

Código no GitHub Issues 
git clone https://github.com/elyosemite/epistulamail.git
cd epistulamail
pnpm install
./scripts/setup-build-tools.ps1
pnpm tauri dev      # rodar em desenvolvimento
pnpm tauri build    # gerar o instalador
