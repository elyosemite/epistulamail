Política de privacidade

O Epistula é um programa de e-mail que roda no seu computador. Não existe conta do Epistula, servidor do Epistula que receba as suas mensagens nem coleta de dados de uso. Esta página diz o que o programa acessa, onde guarda e com quem ele se conecta.

Quem somos

O Epistula é um projeto de código aberto mantido por Yuri Melo. O código está em github.com/elyosemite/epistulamail, e qualquer pessoa pode conferir o que está escrito aqui.

Dados que o Epistula acessa

Quando você conecta uma conta Google, o Epistula pede ao Google permissão para:

  • Ler, enviar e organizar e-mails (escopo https://mail.google.com/), pelo IMAP e pelo SMTP. É o único escopo do Google que dá acesso a esses protocolos.
  • Saber quem é você (escopos openid, email e profile): o seu endereço de e-mail, o nome e a foto do perfil, para mostrar a conta no app.

Esses dados são usados só para mostrar, buscar, escrever, enviar e organizar os seus e-mails dentro do app, a seu pedido. Eles não são usados para publicidade, não são vendidos, não são compartilhados com ninguém e não são usados para treinar modelos de inteligência artificial.

Onde os dados ficam

  • As mensagens, os contatos, as pastas e as configurações ficam só no seu computador, num banco de dados cifrado com AES-256 (SQLCipher).
  • A chave desse banco e os tokens de acesso às contas ficam no Gerenciador de Credenciais do Windows, protegidos pela sua sessão.
  • A sua senha do Google nunca passa pelo Epistula: o login acontece na página do Google, no seu navegador.
  • Os registros de diagnóstico do app não contêm conteúdo de mensagens, endereços, assuntos, senhas ou tokens.

Com quem o Epistula se conecta

  • Google: para o login (OAuth), para receber e enviar e-mails (IMAP e SMTP) e para cancelar o acesso quando você sai da conta.
  • Servidores de chaves OpenPGP (como keys.openpgp.org): só quando você pede para procurar a chave de alguém.
  • Imagens externas de um e-mail: ficam bloqueadas e só são baixadas, direto do servidor de quem enviou, quando você permite naquela mensagem.

O Epistula não envia dados para nenhum servidor próprio, nem para serviços de análise, publicidade ou relatórios de erro.

Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Epistula's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Como apagar os seus dados

  • Sair de uma conta no Epistula cancela o acesso junto ao Google e, se você escolher, apaga do computador as mensagens daquela conta.
  • Desinstalar o Epistula pelo Windows remove o programa; os dados ficam em %APPDATA%\br.com.epistula.desktop e as credenciais no Gerenciador de Credenciais do Windows (itens "epistula"), e podem ser apagados por lá.
  • Você também pode cancelar o acesso a qualquer momento em myaccount.google.com/permissions.

Crianças

O Epistula não é dirigido a menores de 13 anos e não coleta dados de ninguém.

Mudanças

Se esta política mudar, a nova versão é publicada nesta página, com a data no topo, e o histórico fica no repositório do projeto.

Contato

Dúvidas sobre privacidade: abra uma issue no GitHub. Para relatar um problema de segurança em sigilo, use a página de segurança do projeto.
