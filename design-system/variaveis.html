tokens.css

Variáveis CSS

Os tokens do design system: cada cor, tamanho, espaço e tempo que o app, o site e as docs usam, guardados como variáveis CSS em tokens.css. Trocar um valor aqui muda tudo que depende dele, nos dois temas.

O que é um token
Um nome com significado ligado a um valor. --color-text-danger diz "texto de erro", e o valor por trás (um vermelho) muda no tema escuro sem que nenhuma tela precise saber disso.
Como usar
Sempre o token, nunca o valor solto: color: var(--color-text-subtle) em vez de #44546F. Escolha pelo significado ("texto de apoio"), não pela aparência ("cinza").
Como ler os nomes
O nome vai do geral ao específico: tipo (color, space, font), depois o papel (text, surface, border) e por fim a variação (subtle, danger, hovered). Os espaços seguem uma base de 8px: --space-100 vale 8px e --space-050, 4px.
Temas
O tema segue o sistema operacional. data-theme="light" ou data-theme="dark" no <html> força um dos dois. A coluna "Valor agora" abaixo mostra o valor do tema ativo; use o botão de tema do topo para comparar.
Três níveis
Hoje quase tudo é semântico (o que o token significa). A convenção para valores brutos e para ajustes de um só componente está em Governança.

Catálogo

Todos os tokens do tema claro e os gradientes das páginas de destaque, agrupados por assunto. Clique no nome de um token para copiar o var() pronto.

Usar no projeto

Importe tokens.css antes de components.css. As fontes vêm dos pacotes @fontsource no app, no site e nas docs; só estas páginas de documentação carregam do Google Fonts.

<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">

/* Uso: sempre o token semântico */
.minha-linha { color: var(--color-text-subtlest); font: var(--font-body); padding: var(--space-150) var(--space-200); }
