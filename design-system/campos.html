Formulário em duas colunas

Dois lados independentes, como entrada e saída de uma conta, lado a lado com um gap. Cada coluna é um .settings__group; abaixo de --layout-form-column de largura, o formulário passa a uma coluna.

Entrada

Saída

Quando usar
Quando os dois lados são independentes e precisam ser lidos juntos, como entrada e saída de uma conta. Não use para uma sequência única de campos.
Quebra
O grid usa auto-fit: com menos de uma coluna mínima por lado, os grupos ficam um abaixo do outro, sem rolagem horizontal.
Gap
O espaço entre as colunas é var(--space-300); dentro de cada grupo, o gap é o do .settings__group.
