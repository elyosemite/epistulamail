EpistulaMail v1.0

Design System

Fundamentos, componentes e tokens do cliente de e-mail Epistula. A base é o Atlassian Design System: estrutura azul nítida, superfícies neutras e tipografia pensada para telas densas, adaptadas a uma caixa de entrada que precisa ser lida rápido e respondida com um gesto.

  • Referência Atlassian Design System
  • Conformidade WCAG 2.2 AA
  • Temas claro e escuro
  • Arquivos tokens.css · components.css
