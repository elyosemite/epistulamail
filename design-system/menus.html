Mover para
.menu--wide com .menu__search (filtra as pastas), "Mais recentes" (5), .menu__form para criar pasta e "Selecionar outra pasta…", que abre o .folder-picker. Sem resultado, .menu__empty.
Sinalizar
Cada prazo mostra a data em .menu-item__meta. Na lista e na leitura o prazo vira .lozenge: --moved para hoje, neutro para datas futuras, --overdue para atrasada e --success para concluída.
