Lozenge

O lozenge mostra o status de uma mensagem ou de uma peça. É sempre uma palavra, nunca um número: para contar use o badge.

Sutil e forte
Use o sutil, em linha com o texto. O forte só quando o status é o principal da tela.
Não só cor
O sentido está na palavra, e a cor só reforça. Não troque o texto por um ponto colorido.
Maturidade
O DS usa o lozenge para mostrar a maturidade de cada página (Governança).
